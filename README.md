# Smart File Manager
Smart File Manager, but it's not a classical Smart File manager, which usually are only based on extensions.

Type:
- Extensions
- URL ( containing that URL as a source )
- File-Name pattern (using wild card, or absolute)
- Size ('less-than', 'greater-than', only MB)
- Age (According to Modification Date)

Actions:
- Archive (make a .zip/.tar and remove the archived file)
	- Where to archive
- Move
	- where to move
- Remove
- Rename
	- Format to rename it for, only supporting `{name}, {date}, {size}, {extension}`
